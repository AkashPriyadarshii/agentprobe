Enforce Quality Gates in CI/CD

Block pull requests that introduce regressions in agent readability or block AI crawlers before merging.

# .github/workflows/agent-readiness.yml
name: Agent Readiness Gate
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run agentprobe
        run: npx @akashpriyadarshii/agentprobe ./dist --min-score 85 --json > report.json
