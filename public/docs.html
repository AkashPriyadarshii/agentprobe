Docs

Install and run

npx @akashpriyadarshii/agentprobe https://your-site.com
npm install -g @akashpriyadarshii/agentprobe
agentprobe https://your-site.com

Audit a local build

agentprobe ./dist --min-score 85

Scaffold missing manifests

agentprobe init

You get llms.txt, a 15-bot robots.txt, .well-known/ai-catalog.json, and .well-known/mcp.json in your public dir.

The 5 pillars

Bot Accessibility20 pts - robots.txt across 15 AI crawlers, sitemap
LLM Manifest20 pts - /llms.txt, /llms-full.txt, token budget
Structured Context20 pts - JSON-LD, landmarks, headings
Actionability20 pts - markdown negotiation, aria labels, SSR content
Protocol Discovery20 pts - ai-catalog.json, mcp.json, skills, x402

Flags

--min-score <n>Pass threshold 0-100, default 80
--jsonMachine JSON on stdout
--plainPlain text for agents and scripts
--summaryGitHub Step Summary markdown
--no-colorDisable ANSI colors
-q, --quietReport only

Exit codes

  • 0: score meets threshold
  • 1: score below threshold
  • 2: bad target, network failure, parse failure

CI gate

uses: AkashPriyadarshii/agentprobe@v1
with:
  target: 'https://preview.your-site.com'
  min-score: '85'
npx @akashpriyadarshii/agentprobe ./dist --min-score 80 --json > agent-report.json
