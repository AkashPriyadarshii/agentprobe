agentprobe Documentation

Every flag, check, and scoring rule in agentprobe.

Install & Quickstart

shell
npx @akashpriyadarshii/agentprobe https://your-site.com

5 Audit Pillars (100 Points)

PillarWeightWhat it checks
Crawler Access20 ptsrobots.txt, AI bot rules, Content-Signal
llms.txt20 pts/llms.txt H1, blockquote, Markdown links
Structured Context20 ptsJSON-LD, canonicals, OG tags, SSR HTML
Semantic DOM20 ptsLandmarks, real buttons/links, ARIA labels
Protocol Discovery20 pts.well-known/ai-catalog.json, MCP, Markdown

CLI Flags

FlagDefaultDescription
--min-score <n>80Exit non-zero if total score is below n
--jsonfalseOutput machine-readable JSON report
--timeout <ms>10000Request timeout per endpoint

CI Gate

.github/workflows/agentprobe.yml
- run: npx @akashpriyadarshii/agentprobe https://your-site.com --min-score 85

Node API

index.mjs
import { auditTarget } from '@akashpriyadarshii/agentprobe';
const report = await auditTarget('https://your-site.com');
console.log(report.totalScore);
