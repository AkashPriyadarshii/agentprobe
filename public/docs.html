Installation & Quickstart

Run instantly with npx without installing:

npx @akashpriyadarshii/agentprobe https://your-site.com

Or install globally to use anywhere in terminal:

npm install -g @akashpriyadarshii/agentprobe
agentprobe https://your-site.com

Local Static Build Auditing

Audit a production static export folder (e.g. dist, build, or out) before deploying:

agentprobe ./dist --min-score 85

Exit code is 0 if score ≥ 85, or 1 if regressions exist.

Auto-Scaffold Missing Manifests

Interactively scaffold compliant manifests for your project:

agentprobe init

Generates a spec-compliant llms.txt, a 15-bot permissive robots.txt, and discovery manifests (.well-known/ai-catalog.json and .well-known/mcp.json).

The 5 Audit Pillars (20 pts each, 100 max)

Pillar Max What it inspects
1. Bot Accessibility 20 pts robots.txt crawl permissions across 15 AI bots (GPTBot, ClaudeBot, PerplexityBot, ByteSpider, etc.) + XML sitemap presence.
2. LLM Manifest 20 pts /llms.txt and /llms-full.txt compliance, H1 syntax, token density, and section taxonomy.
3. Structured Context 20 pts Schema.org JSON-LD graphs, HTML5 landmarks (<main>, <nav>), and heading hierarchies.
4. Actionability 20 pts Markdown content negotiation (Accept: text/markdown), interactive button ARIA labels, and SSR hydration traps.
5. Protocol Discovery 20 pts Agentic Resource Discovery (ai-catalog.json), Model Context Protocol (mcp.json), and x402 payment headers.

CLI Flags & Options

Flag Description
--min-score <n> Minimum passing score threshold (0-100, default 80).
--json Outputs machine-readable JSON to stdout for scripts or telemetry.
--plain Plain text without ANSI formatting for AI coding agents.
--summary Outputs GitHub Step Summary markdown for pull requests.
--no-color Disables terminal ANSI colors (respects NO_COLOR=1).
-q, --quiet Suppresses banners, outputs final status and exit code only.

Exit Codes

  • 0: Audit passed (score ≥ threshold).
  • 1: Audit failed (score < threshold).
  • 2: Invalid target, unreachable network host, or parse error.

CI/CD Pipeline Setup

Add to .github/workflows/agent-readiness.yml:

name: Agent Readiness Gate
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Audit Preview URL
        uses: AkashPriyadarshii/agentprobe@v1
        with:
          target: 'https://preview.your-site.com'
          min-score: '85'
